# Generated art assets

All twelve images were created for Immortal Blossoms using the built-in `image_gen.imagegen` tool. No API/CLI fallback was used. Images were visually inspected and copied into `assets/`; no external runtime image URLs are required. The five heroine atlases provide thirty unique original portraits, with no portrait shared by multiple heroines. Runtime mapping is exported from `assets/hero-art.js` as `HERO_ART`.

## Atlas layout

Each heroine atlas is 1254 × 1254, containing 3 columns × 2 rows of 418 × 627 (2:3) portraits. Reading order is left to right across the top row, then left to right across the bottom row.

- `enemies-atlas.png`: 1254 × 1254, 3 columns × 2 rows of portrait panels. Top: dragon, fox, stag. Bottom: wraith, phoenix, guardian.
- `modes-atlas.png`: 2048 × 768, 3 columns × 2 rows of 16:9 landscape panels. Top: pagoda, raid, secret realm. Bottom: shrine, tournament, medicine valley.
- CSS atlas rendering: `background-size: 300% 200%` and x positions `0%`, `50%`, `100%`; y positions `0%`, `100%`.
- `card-frame.png`: 1024 × 1536 RGBA; genuine alpha verified at center (0), intended as a portrait overlay.
- `landscape-frame.png`: 1672 × 941 RGBA; genuine alpha verified at center (0), intended as a landscape mode tile overlay.
- `home-splash.png`: 1672 × 941, four founding heroine composition, generated to match the supplied home mockup.
- `summon-splash.png`: 1672 × 941, lotus heroine and white-gold dragon composition.
- `sanctuary.png`: 1672 × 941, reusable empty terrace battle and formation environment.

All actual generated dimensions above were verified from output. Request sizes in prompts below express desired sizes; the built-in tool selected its output dimensions. Portrait art was created as atlases and consumed with CSS positions; no slicing or external image editing was performed. Further expression, outfit and cinematic cut-in variants remain separate production work.
